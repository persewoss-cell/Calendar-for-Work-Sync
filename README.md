# 업무 캘린더 (Calendar for Work Sync)

바탕화면에 투명하게 붙여 두고 쓰는 업무용 달력입니다. PC 앱, 휴대폰(PWA), 구글 캘린더가 서로 동기화됩니다.
`xdiarys`(캘린더 목록) 프로그램의 사용 방식과 설정 항목을 참고해 직접 만든 프로그램입니다.

```
┌────────────┐   실시간(socket.io)   ┌──────────────────┐   양방향 동기화   ┌──────────────┐
│ PC 앱      │◀────────────────────▶│ 서버 (Node.js)    │◀────────────────▶│ 구글 캘린더   │
│ (Electron) │                      │  + MongoDB Atlas │  (일정마다 켜기/끄기) └──────────────┘
└────────────┘                      └──────────────────┘
┌────────────┐                               ▲
│ 휴대폰 PWA │◀──────────────────────────────┘
└────────────┘
```

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `server/` | Express API, MongoDB(Mongoose) 모델, 구글 로그인, 구글 캘린더 동기화, 실시간 알림 |
| `web/` | React 달력 화면. 브라우저·휴대폰(PWA)·PC 앱이 모두 이 화면을 씁니다 |
| `desktop/` | Electron PC 앱 (투명 창, 트레이, 단축키, 바탕화면 스티커 메모 창) |

## 기능

**달력 화면**
- 4가지 보기: 변동 월, 전체 월, 고정 단일 행(한 주), 변동 단일 행(오늘이 가운데)
- 최대 행, 지나간 주 표시, 최대 열 수, 시작 요일, 첫 번째 주(학기 주차) 설정
- 유리 효과, 투명도, 그림자, 월 간격, 주 번호, 제목 표시줄 자동 숨김
- 오늘 칸 빛나는 테두리, 쉬는날(토·일 등) 배경색, 매월 1일에 「11월」 표시

**일정 편집**
- 날짜 칸을 누르면 그 자리에서 바로 입력합니다. Enter로 새 줄을 만들고 Esc나 바깥을 누르면 저장됩니다. 줄을 비우면 삭제됩니다.
- 일정 글자를 누르면 상세 창이 열립니다. 시간, 여러 날, 반복(매일·매주·격주·매월·매년·평일), 색상, 알림, 메모, 완료를 설정할 수 있습니다.
- 끌어서 다른 날짜로 옮기기
- 체크박스로 완료 처리하고, 완료한 일은 맨 아래로 내립니다. 완료 표시와 아이콘도 켜고 끌 수 있습니다.
- 미완료 작업 자동 연기: 지난 30일 안의 끝내지 못한 일을 오늘로 옮깁니다.
- 목록 스타일(없음·번호·점), 셀 간격, 줄 간격, 텍스트 배경

**휴일과 절기**
- 대한민국 공휴일: 설날·추석 연휴, 부처님오신날, 대체공휴일 규칙, 선거일
- 미국 공휴일(선택), 기념일(어버이날, 스승의 날, 추수감사절 등)
- 24절기(천문 계산), 음력 날짜(한국천문연구원 데이터 기반)

**스티커 메모·D-day 카드**
- 체크리스트 메모와 D-day(매년 반복 기념일 포함) 카드
- PC 앱에서는 바탕화면에 각각 따로 붙는 창으로 뜨고, 웹에서는 끌어서 옮기는 카드로 뜹니다.

**알림과 기타**
- 알림 시간이 되면 알림창과 함께 소리(작은 별, 벨, 차임 등)가 납니다.
- 내용 검색, 날짜 선택, 예약된 작업 숨기기(화면 가리기), 인쇄
- 내보내기: 전체 백업(JSON), iCalendar(.ics), 엑셀용 CSV. 불러오기: JSON, ICS
- 단축키: 캘린더 숨기기(Ctrl+Alt+H), 작업 숨기기(Ctrl+Alt+F), 메모 숨기기(Ctrl+Alt+B), 편집 완료(Ctrl+Alt+E)
- PC 앱: Windows 시작 시 실행, 트레이 아이콘, 위치 및 크기 조정 모드

**동기화**
- 같은 구글 계정으로 로그인한 PC와 휴대폰에 즉시 반영됩니다.
- **구글 캘린더 양방향 동기화**는 아래 「구글 캘린더 반영 방식」을 참고하세요.

## 구글 캘린더 반영 방식

- 계정 설정에서 **구글 캘린더 동기화 사용**을 켜고 연결할 캘린더를 고릅니다(기본 캘린더나 「업무」 같은 별도 캘린더).
- 일정 상세 창마다 **「구글 캘린더에 반영」 스위치**가 있습니다.
  - **켜기**: 구글 캘린더에 올라가고, 이후 수정·삭제도 따라갑니다.
  - **끄기**: 구글 캘린더에서만 지워지고 이 앱에는 남습니다. 다시 켜면 다시 올라갑니다.
- **새 일정을 구글에 자동 반영**: 새로 만드는 일정의 스위치 기본값입니다.
- **구글에서 만든 일정 가져오기**: 구글 캘린더(휴대폰 구글 캘린더 앱 등)에서 만든 일정도 이 앱으로 가져옵니다. 끄면 이 앱에서 올린 일정의 변경·삭제만 가져옵니다.
- **지금 보이는 기간 일괄 처리**: 화면에 보이는 달의 일정을 한 번에 반영하거나 해제합니다.
- 동기화는 3분마다 자동으로 돌고, 위쪽 구름 아이콘을 누르면 바로 실행됩니다.
- 구글 캘린더에서 일정을 지우면 이 앱에서도 지워집니다.
- 두 곳에서 동시에 고쳤다면 더 나중에 고친 쪽이 남습니다.
- 색상과 완료 여부는 구글 일정의 비공개 속성에 저장되므로 기기를 바꿔도 유지됩니다.

## 설치 1단계: MongoDB Atlas

1. https://www.mongodb.com/atlas 에서 무료(M0) 클러스터를 만듭니다.
2. **Database Access**에서 사용자와 비밀번호를 만듭니다.
3. **Network Access**에서 `0.0.0.0/0`을 허용합니다. 클라우드 서버의 IP가 고정되지 않기 때문입니다.
4. **Connect → Drivers**에서 연결 문자열을 복사해 `MONGODB_URI`에 넣습니다. 주소 끝 `/` 뒤에 DB 이름 `workcal`을 붙이세요.

## 설치 2단계: 구글 클라우드 설정

1. https://console.cloud.google.com 에서 프로젝트를 만듭니다.
2. **API 및 서비스 → 라이브러리**에서 **Google Calendar API**를 **사용**으로 바꿉니다.
3. **OAuth 동의 화면**을 설정합니다.
   - 사용자 유형: 외부. 앱 이름과 이메일을 입력합니다.
   - 범위에 `.../auth/calendar`, `email`, `profile`, `openid`를 추가합니다.
   - **테스트 사용자**에 본인 구글 계정을 추가합니다. 「테스트」 상태에서는 등록한 계정만 로그인할 수 있습니다.
4. **사용자 인증 정보 → OAuth 클라이언트 ID 만들기 → 웹 애플리케이션**을 만듭니다.
   - 승인된 리디렉션 URI:
     - `https://<서버주소>/auth/google/callback`
     - (로컬 개발 시) `http://localhost:4000/auth/google/callback`
5. 클라이언트 ID와 보안 비밀을 `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`에 넣습니다.

> 「테스트」 상태의 앱은 구글 정책상 약 7일마다 다시 로그인해야 할 수 있습니다. 혼자 오래 쓸 때는 동의 화면을 **프로덕션**으로 게시하세요. 미인증 앱 경고가 한 번 뜨지만, 본인만 쓴다면 「고급 → 이동」으로 넘어가면 됩니다.

## 설치 3단계: 서버 배포 (예: Render)

1. 이 저장소를 Render에 연결하고 **New → Blueprint**로 `render.yaml`을 선택합니다.
2. 환경 변수 `MONGODB_URI`, `PUBLIC_URL`(Render가 준 주소), `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`을 입력합니다.
3. 배포가 끝나면 `https://<주소>/healthz`가 `{"ok":true,"db":true}`인지 확인합니다.

Docker로 띄울 때는 다음 명령을 씁니다.

```bash
docker build -t workcal .
```

```bash
docker run -p 4000:4000 --env-file .env workcal
```

> Render 무료 요금제는 15분 동안 접속이 없으면 잠듭니다. 잠든 동안에는 3분마다 도는 구글 자동 동기화가 멈추고, 다음 접속 때 다시 돕니다. 항상 켜 두려면 유료 요금제나 다른 호스팅을 쓰세요.

## 설치 4단계: PC 앱 (Windows)

- **설치 파일 받기**: GitHub 저장소의 **Actions → Build desktop app → Run workflow**를 실행하면 `업무 캘린더 Setup.exe`가 결과물로 나옵니다. `v1.0.0` 같은 태그를 올려도 만들어집니다.
- **직접 만들기**(Windows PC에서):

```bash
cd desktop
```

```bash
npm install
```

```bash
npm run dist:win
```

처음 실행하면 서버 주소를 묻습니다(예: `https://my-calendar.onrender.com`). **구글 계정으로 로그인**을 누르면 기본 브라우저가 열리고, 로그인을 마치면 자동으로 앱에 돌아옵니다(`workcal://` 링크).

- ☰ → **위치 및 크기**로 창을 원하는 곳에 배치합니다. 트레이 아이콘에서도 할 수 있습니다.
- 작업 표시줄에는 나타나지 않습니다. 트레이 아이콘으로 보이기, 숨기기, 종료를 할 수 있습니다.

## 설치 5단계: 휴대폰

PC 앱의 📱 아이콘을 누르면 QR 코드가 나옵니다. 찍어서 같은 구글 계정으로 로그인하면 됩니다.

- 안드로이드(크롬): ⋮ → 「홈 화면에 추가」 / 「앱 설치」
- 아이폰(사파리): 공유 → 「홈 화면에 추가」

휴대폰에서는 날짜를 누르면 그날의 일정 목록이 아래에서 올라옵니다.

## 로컬 개발

```bash
npm install
```

```bash
cp .env.example .env
```

`.env`에 `MONGODB_URI=mongodb://127.0.0.1:27017/workcal`, `DEV_LOGIN=true`, `WEB_URL=http://localhost:5173`을 설정하고 실행합니다.

```bash
npm run dev:server
```

```bash
npm run dev:web
```

http://localhost:5173 에서 「개발용으로 로그인」으로 들어갈 수 있습니다. PC 앱을 개발 서버에 붙이려면 다음과 같이 실행합니다.

```bash
cd desktop && WORKCAL_SERVER=http://localhost:4000 npm start
```

테스트는 다음 명령으로 돌립니다. 공휴일, 24절기, 음력, 반복 일정, ICS, 구글 일정 변환을 확인합니다.

```bash
npm test
```

## 알려진 한계

- **바탕화면 고정**: Windows에서 창은 작업 표시줄에 나타나지 않고 다른 창 아래에 놓이지만, `Win+D`(바탕화면 보기)를 누르면 함께 숨겨집니다. 원본처럼 바탕화면 층에 완전히 박아 넣으려면 네이티브 모듈이 필요해 아직 넣지 않았습니다. Linux에서는 바탕화면 층에 붙습니다.
- **모바일 알림**: PWA는 앱이 열려 있을 때만 자체 알림을 띄웁니다. 앱을 닫아 둔 휴대폰에서도 알림을 받으려면 일정을 구글 캘린더에 반영하세요. 구글 캘린더 앱이 알림을 대신 보내 줍니다.
- **자동 업데이트**: 설정 항목은 있지만 업데이트 배포 서버는 아직 연결하지 않았습니다.
- **언어**: English를 고르면 요일과 제목 표시줄만 영어로 바뀝니다.
