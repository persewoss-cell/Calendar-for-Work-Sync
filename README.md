# 업무 캘린더 (Calendar for Work Sync)

바탕화면에 투명하게 붙여 두고 쓰는 업무용 달력입니다. PC 앱과 휴대폰(PWA)이 실시간으로 동기화됩니다.
`xdiarys`(캘린더 목록) 프로그램의 사용 방식과 설정 항목을 참고해 직접 만든 프로그램입니다.

```
┌────────────┐   실시간(socket.io)   ┌──────────────────┐
│ PC 앱      │◀────────────────────▶│ 서버 (Node.js)    │
│ (Electron) │                      │  + MongoDB Atlas │
└────────────┘                      └──────────────────┘
┌────────────┐                               ▲
│ 휴대폰 PWA │◀──────────────────────────────┘
└────────────┘
```

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `server/` | Express API, MongoDB(Mongoose) 모델, 아이디·비밀번호 로그인, 실시간 알림 |
| `web/` | React 달력 화면. 브라우저·휴대폰(PWA)·PC 앱이 모두 이 화면을 씁니다 |
| `desktop/` | Electron PC 앱 (투명 창, 트레이, 단축키, 바탕화면 스티커 메모 창) |

## 기능

**달력 화면**
- 4가지 보기: 변동 월, 전체 월, 고정 단일 행(한 주), 변동 단일 행(오늘이 가운데)
- 최대 행, 지나간 주 표시, 최대 열 수, 시작 요일, 첫 번째 주(학기 주차) 설정
- 유리 효과, 투명도, 그림자, 월 간격, 주 번호, 제목 표시줄 자동 숨김
- 오늘 칸 빛나는 테두리, 토요일(연한 파랑)·일요일과 공휴일(연한 빨강) 배경색, 매월 1일에 「11월」 표시
- 캘린더 글꼴: 공통 글꼴 + 상단 제목·요일·날짜 숫자·월 표시·휴일 이름·절기·음력마다 글꼴(비우면 공통 글꼴)·크기·색·굵게를 따로 설정
- 편집 내용 공통 글꼴 및 크기: 일정 글자의 기본 글꼴·크기·색. 바꿀 때 입력창에서 직접 바꾼 글자에도 적용할지 묻습니다.
- 설정 창은 제목 줄 오른쪽의 톱니바퀴로 바로 엽니다. 바꾸는 즉시 달력에 반영되고, 제목 줄을 끌어서 옮길 수 있습니다. PC 앱에서는 별도 창으로 떠서 달력 밖 어디로든 옮길 수 있습니다.
- 월 간격: 달마다 그 달의 날짜 칸 바깥을 테두리로 감쌉니다.

**일정 편집**
- 날짜 칸을 **더블클릭**하면 그 칸을 가리지 않도록 오른쪽(자리가 없으면 왼쪽)에 입력창이 뜹니다. **Enter = 저장**, **Ctrl+Enter 또는 Alt+Enter = 줄바꿈(새 일정)** 입니다. 줄을 지우면 그 일정이 삭제됩니다. 휴대폰에서는 한 번 누르면 열리고, Enter가 줄바꿈, ✓가 저장입니다.
- 입력창 도구: 굵게·기울임·밑줄·취소선, 글자색(X = 기본 색으로), **칸 배경색**, 글꼴(PC 기본 글꼴 + 무료 한글 웹 글꼴 30여 종), 크기(pt), 이 날짜의 목록 모양, 서식 지우기. 서식은 고른 글자에만 적용되고 달력 칸에도 그대로 보입니다.
- 입력창의 시계 아이콘을 누르면 상세 창이 열립니다. 시간, 여러 날, 반복(매일·매주·격주·매월·매년·평일), 색상, 알림, 메모, 완료를 설정할 수 있습니다.
- **접기**: 제목 줄을 더블클릭하면 왼쪽 위에 작은 사각 아이콘만 남고, 아이콘을 한 번 누르면 다시 펼쳐집니다. PC 앱에서는 창 자체가 아이콘 크기로 줄어듭니다.
- 끌어서 다른 날짜로 옮기기
- 체크박스로 완료 처리하고, 완료한 일은 맨 아래로 내립니다. 완료한 일정 오른쪽 끝의 작은 휴지통을 누르면 확인한 뒤 삭제합니다(반복 일정은 그 날짜만).
- 미완료 작업 자동 연기: 지난 30일 안의 끝내지 못한 일을 오늘로 옮깁니다.
- 목록 스타일(없음·번호·점), 셀 간격, 줄 간격, 텍스트 배경

**휴일과 절기**
- 대한민국 공휴일: 설날·추석 연휴, 부처님오신날, 대체공휴일 규칙, 선거일
- 미국 공휴일(선택), 기념일(어버이날, 스승의 날, 추수감사절 등)
- 24절기(천문 계산), 음력 날짜(한국천문연구원 데이터 기반)

**스티커 메모·D-day 카드**
- 체크리스트 메모와 D-day(매년 반복 기념일 포함) 카드
- PC 앱에서는 바탕화면에 각각 따로 붙는 창으로 뜨고, 웹에서는 끌어서 옮기는 카드로 뜹니다.

**알림과 기타**
- 알림 시간이 되면 알림창과 함께 소리(작은 별, 벨, 차임 등)가 납니다.
- 내용 검색, 날짜 선택, 예약된 작업 숨기기(화면 가리기), 인쇄
- 내보내기: 전체 백업(JSON), iCalendar(.ics), 엑셀용 CSV. 불러오기: JSON, ICS
- 단축키: 캘린더 숨기기(Ctrl+Alt+H), 작업 숨기기(Ctrl+Alt+F), 메모 숨기기(Ctrl+Alt+B), 편집 완료(Ctrl+Alt+E)
- PC 앱: Windows 시작 시 실행, 트레이 아이콘, 위치 및 크기 조정 모드

**계정**
- 아이디·비밀번호로 가입하고 로그인합니다. 한 번 로그인하면 180일 동안 유지됩니다.
- 사람마다 일정·메모·설정이 따로 저장되어 서로 섞이지 않습니다.
- 계정 설정에서 이름과 비밀번호를 바꿀 수 있습니다.
- 쓸 사람이 모두 가입한 뒤 `ALLOW_SIGNUP=false`로 바꾸면 더 이상 아무도 가입할 수 없습니다.

## 설치 1단계: MongoDB Atlas

1. https://www.mongodb.com/atlas 에서 무료(M0) 클러스터를 만듭니다. 지역은 서버와 같은 **Singapore**를 권합니다.
2. **Security → Database Access**에서 DB 사용자를 만듭니다. 비밀번호는 영문과 숫자로만 만드세요.
3. **Security → Network Access**에서 **Allow Access from Anywhere**(`0.0.0.0/0`)를 추가합니다.
4. **Connect → Drivers**에서 연결 문자열을 복사한 뒤 세 군데를 고칩니다.
   - `<db_username>`을 사용자 이름으로 바꿉니다.
   - `<db_password>`를 비밀번호로 바꿉니다.
   - 맨 끝 `/` 뒤에 `workcal`을 붙입니다.

   ```
   mongodb+srv://workcal:비밀번호@cluster0.xxxxx.mongodb.net/workcal
   ```

## 설치 2단계: 서버 배포 (Render)

1. https://render.com 에 GitHub 계정으로 가입합니다.
2. **New → Blueprint**에서 이 저장소를 고릅니다. `render.yaml`을 자동으로 읽습니다.
3. 환경 변수 두 개를 입력합니다.
   - `MONGODB_URI`: 1단계에서 만든 연결 문자열
   - `PUBLIC_URL`: Render가 정해 준 주소 (예: `https://workcal-xxxx.onrender.com`). 처음에는 비워 두고, 배포 후 주소를 확인해서 넣은 뒤 다시 배포해도 됩니다.
   - `JWT_SECRET`은 자동으로 만들어집니다.
4. 배포가 끝나면 `https://<주소>/healthz`가 `{"ok":true,"db":true}`인지 확인합니다.

Docker로 띄울 때는 다음 명령을 씁니다.

```bash
docker build -t workcal .
```

```bash
docker run -p 4000:4000 --env-file .env workcal
```

> Render 무료 요금제는 15분 동안 접속이 없으면 잠듭니다. 잠든 뒤 처음 열 때 30초~1분쯤 걸립니다. 데이터는 MongoDB에 있으니 사라지지 않습니다.

## 설치 3단계: 가입하기

1. 브라우저에서 서버 주소를 열고 **회원가입**으로 아이디를 만듭니다.
2. 같이 쓸 사람도 같은 주소에서 각자 가입합니다.
3. 모두 가입했으면 Render 환경 변수 `ALLOW_SIGNUP`을 `false`로 바꿔 가입을 막습니다. 서버 주소를 아는 다른 사람이 가입하지 못하게 하기 위해서입니다.

## 설치 4단계: PC 앱 (Windows)

1. GitHub 저장소 → **Actions → Release desktop app → Run workflow**를 누릅니다.
2. 버전에 `1.0.0`을 넣고 실행합니다. 10분쯤 뒤 저장소의 **Releases**에 `WorkCal-Setup-1.0.0.exe`가 올라옵니다.
3. 받아서 설치합니다. 「Windows의 PC 보호」 창이 뜨면 **추가 정보 → 실행**을 누르세요. 서명하지 않은 개인 프로그램이라 뜨는 경고입니다.
4. 처음 실행하면 서버 주소를 묻습니다(예: `https://workcal-xxxx.onrender.com`). 그다음 앱 안에서 아이디와 비밀번호로 로그인합니다.

- ☰ → **위치 및 크기**로 창을 원하는 곳에 배치합니다. 트레이 아이콘에서도 할 수 있습니다.
- 작업 표시줄에는 나타나지 않고 알림 영역(트레이)에만 아이콘이 뜹니다. 트레이 아이콘으로 보이기, 숨기기, 종료를 할 수 있습니다.
- `Win+D`(바탕화면 보기)를 눌러도 달력과 메모가 바탕화면에 그대로 남습니다.

### 업데이트

- **달력 화면·기능 수정**(`web/`, `server/`): Render에 배포되면 끝입니다. PC 앱이 화면을 서버에서 불러오므로 앱을 다시 켜거나 트레이 → **새로고침**하면 바로 반영됩니다. 새 설치 파일이 필요 없습니다.
- **PC 앱 자체 수정**(`desktop/`): **Release desktop app**을 이전보다 큰 버전 번호(예: `1.0.1`)로 실행합니다. 설치된 PC 앱은 다음 실행 때 「새 버전이 있습니다」라고 한 번 묻습니다. **업데이트**를 누르면 자동으로 받아서 설치하고 다시 시작합니다.
- 캘린더 설정 → 고급 → **자동 업데이트 확인**을 끄면 묻지 않습니다. 트레이 메뉴 **업데이트 확인**으로 직접 확인할 수도 있습니다.

## 설치 5단계: 휴대폰

PC 앱의 📱 아이콘을 누르면 QR 코드가 나옵니다. 찍어서 같은 아이디로 로그인하면 됩니다.

- 안드로이드(크롬): ⋮ → 「홈 화면에 추가」 / 「앱 설치」
- 아이폰(사파리): 공유 → 「홈 화면에 추가」

휴대폰에서는 날짜를 누르면 그날의 일정 목록이 아래에서 올라옵니다.

## 로컬 개발

```bash
npm install
```

```bash
cp .env.example .env
```

`.env`의 `MONGODB_URI`를 로컬 MongoDB(`mongodb://127.0.0.1:27017/workcal`)나 Atlas 주소로 바꾸고 실행합니다.

```bash
npm run dev:server
```

```bash
npm run dev:web
```

http://localhost:5173 에서 가입하고 들어갈 수 있습니다. PC 앱을 개발 서버에 붙이려면 다음과 같이 실행합니다.

```bash
cd desktop && WORKCAL_SERVER=http://localhost:4000 npm start
```

테스트는 다음 명령으로 돌립니다. 공휴일, 24절기, 음력, 반복 일정, ICS, 비밀번호 처리를 확인합니다.

```bash
npm test
```

## 알려진 한계

- **바탕화면 고정**: Windows에서는 달력 창과 메모 창을 바탕화면 창(Progman)에 붙입니다. 그래서 작업 표시줄에 나타나지 않고, `Win+D`를 눌러도 남아 있으며, 다른 프로그램 창보다 항상 아래에 놓입니다. Windows 탐색기가 다시 시작되면 3초 뒤 달력 창이 다시 뜹니다.
- **모바일 알림**: PWA는 앱이 열려 있을 때만 알림을 띄웁니다.
- **비밀번호 찾기**: 이메일을 받지 않으므로 비밀번호를 잊으면 스스로 재설정할 수 없습니다. 이럴 때는 Atlas에서 해당 사용자를 지우고 다시 가입해야 하는데, 사용자를 지워도 그 사람의 일정 데이터는 DB에 남습니다.
- **언어**: English를 고르면 요일과 제목 표시줄만 영어로 바뀝니다.
